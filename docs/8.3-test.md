# 日志与可观测性测试

## 命令

全部是单元与轻集成测试，用内存 `slog.Handler` 或 `prometheus.NewRegistry()` 做替身，不起 API Server，不做真实抓取。

```bash
# 仓库根是多模块 workspace，逐模块进入执行；-count=1 禁缓存
cd core && go test ./logging/... -count=1
cd controller && go test ./internal/logging/... -count=1

# 采样器与丢弃计数带原子操作，跑一次竞态检测
cd core && go test ./logging/... -race -count=1
cd controller && go test ./internal/logging/... -race -count=1

# 静态检查
cd core && go vet ./logging/...
cd controller && go vet ./internal/logging/...
```

## core/logging 的测试文件

| 文件 | 测什么 | 覆盖场景 |
|---|---|---|
| `redact_test.go` | 字符串脱敏与 URL 脱敏 | key=value、key: value、JSON 紧凑与带空格、query 串、键大小写、x-amz 键、非敏感文本不变、URL 去掉 userinfo 与 fragment、敏感查询参数替换、URL 解析失败兜底 |
| `handler_test.go` | 脱敏接进标准日志 | 消息与 error 值脱敏、预挂属性脱敏、分组属性脱敏、普通值保持原样 |
| `sampling_test.go` | 采样率、令牌桶、去重窗口与环境变量 | 按级别采样、丢弃计数按 component 与级别分、突发额度与按秒补充、60 秒去重与下一窗口的 suppressed、采样率为 0 时 Warn 与 Error 零丢失、env 采样率生效与非法值退默认 |
| `errclass_test.go` | 错误分类与采样字段 | 通用分类只认超时与取消、其余记为 io、每条记录带 sampled 与 sample_rate、采样率为 1 时标 sampled=false、有 err 必有 err_class、显式分类不被覆盖、字符串形式的 err 记为 io、无 err 不带 err_class、suppressed 与采样字段共存 |
| `level_test.go` | 级别解析与动态级别端点 | 四级解析与大小写与空白、非法值退 info、GET 与 PUT 契约、非法 body 返回 400、非 GET 与 PUT 返回 405 且带 Allow 头、每次成功修改写审计行、改级对已构造的 logger 立即生效、地址为空时端点立即关闭 |
| `metadata_test.go` | 请求身份读写 | 分层补充时空字段不覆盖已有值、没有写入时返回零值且不 panic |

## 覆盖缺口

| 缺什么 | 优先级 | 怎么补 |
|---|---|---|
| 引号未闭合时吞掉剩余内容这条分支没有用例 | 中 | 送一段引号未闭合的敏感键片段，断言输出里不再出现哨兵值 |
| 采样率环境变量取空串时退默认没有用例 | 低 | 把两个采样率环境变量设为空串，断言退到 1.0 与 0.01 |
| 令牌桶时钟回拨时不计额度这条分支没有用例 | 中 | 把假时钟往回拨一秒，断言令牌数不增加 |
| 去重表键数到阈值时的过期键清理没有用例 | 低 | 用假时钟灌入超过阈值的去重键，断言过期键被清掉 |
| 端点监听失败只记 Error 不返回错误没有用例 | 中 | 传一个已被占用的端口，断言不返回错误 |
| 端点真实监听与上下文取消后的优雅关闭没有用例 | 中 | 起一个回环监听，请求一次后取消上下文，断言端口被释放 |
| 请求体超过 1 KiB 时的截断解析没有用例 | 低 | 送一个带多余字段的 body，断言按首个小 JSON 对象解析 |
| 采样器绑定的组件名读取没有用例 | 低 | 断言构造时传入的组件名原样返回，空采样器返回空串 |
| 控制平面 logger 未初始化时采样器读取返回 nil 没有用例 | 低 | 在构造 logger 之前断言返回 nil，构造之后断言非 nil |
| gRPC metadata 三个关联键的键名没有断言 | 低 | 断言键名固定，改名时测出来 |
