# 实验版本记录

## 记录规则

表里一行是一个版本跑完的一个族，只追加。写入后不改动、不删除。同一版本同一族重跑，追加新行，最后一行为该族的当前记录。

一族全部格子跑完才写行：每格 `summary.csv` 的有效行数达到 3，即 `sampling.reps` 的值；每格判据按 4.3 §3 的阈值判定完毕；各格 `version` 文件的内容一致，版本一列写这个值。

族一列写 4.2 §1 的族 ID。产物目录一列写 `~/tcd/bench/results/` 下的相对路径，格式为 `<族 ID>/<格子>/`，目录内容见 4.4 §7。

判据一列写「通过」或「不通过」。不通过时在括号里写未达的阈值项，例如「不通过（缓存峰值未达声明容量）」。
