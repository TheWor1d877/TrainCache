# S3 合并回源网关测试说明书

## 命令

### 单测与静态检查

```bash
cd gateway && go build ./... && go vet ./... && go test ./... -race -count=1
cd core    && go build ./... && go vet ./... && go test ./... -race -count=1
cd agent   && go build ./... && go vet ./... && go test ./... -race -count=1
```

```bash
make verify-gateway
make verify
make verify-metadata
```

### 契约与集成

```bash
cd gateway && go test ./internal/server/... -run Integration -count=1 -v
cd core    && go test ./objectstore/... -run Gateway -count=1
cd agent   && go test ./svc/... -run 'Backend|Gateway' -count=1
```

### 集群 e2e

```bash
# 前置：kind 集群可达；MinIO 在 minio namespace 且桶里已有可读对象；
#       traincache namespace 已有 ConfigMap traincache-config 与 Secret traincache-objstore；
#       traincache-gateway:dev 与探针镜像已用 ./hack/kind-load.sh 载入集群
#       （探针镜像默认 busybox:latest，TC_PROBE_IMAGE 可指定，CI 固定 busybox:1.36.1）。
bash gateway/e2e/run-k8s.sh
E2E_KEY='dataset-4gib/blocks/shard-00063.tar#15' bash gateway/e2e/run-k8s.sh
TC_E2E_AGENT=1 bash gateway/e2e/run-k8s.sh
TC_E2E_CACHE=1 bash gateway/e2e/run-k8s.sh
```

### 长时稳态

```bash
cd gateway && go test ./internal/server/... -run Soak -race -count=1 -timeout=120s
cd gateway && GATEWAY_SOAK_DURATION=20s GATEWAY_SOAK_CONCURRENCY=8 \
  go test ./internal/server/... -run Soak -race -count=1 -timeout=180s
cd gateway && GATEWAY_SOAK_DURATION=4h GATEWAY_SOAK_CONCURRENCY=32 \
  go test ./internal/server/... -run Soak -count=1 -timeout=5h
```

## 缺口

| 缺什么 | 优先级 | 怎么补 |
|---|---|---|
| 416 `InvalidRange` 没有用例，Range 语法非法与区间越界这两条分支只有实现 | 高 | 在 `range_test.go` 补两条请求，断言状态码 416 与 `Code=InvalidRange` |
| 空键 404 `NoSuchKey` 没有网关侧用例 | 中 | 在 `route_test.go` 请求 `/traincache/`，断言 404 与 `Code=NoSuchKey` |
| 块键 GET 遇到源站真的连不上时回 504 没有用例，`XTraincacheGatewayOriginUnavailable` 只在非块键的直通请求上断过 | 中 | 在 `block_test.go` 把假源站换成已关闭的端口发起块 GET，断言 504、`Code` 与不带 `unavailable` 头 |
| 长时稳态只跑关闭态，开启态下盘上驻写字节与读盘命中的 goroutine 数没有断言 | 中 | 给 `soak_test.go` 加缓存模式开关，重复读同一批 key，断言驻写不超总上限、命中不新增 goroutine |
| 网关只应收到 GET 与 HEAD，`GET /<bucket>?location=` 的缺席没有断言 | 中 | 在 `gateway_test.go` 用记录请求路径的 `RoundTripper` 断言请求列表里没有带 `location` 查询的请求 |
| `Scan` 清理上个进程留下的 `.tmp` 没有断言 | 低 | 在 `TestScanRecoversAccounting` 里先留一个 `.tmp`，断言扫描后它已消失且不计入驻写字节 |
| `TRAINCACHE_GATEWAY_SECURE=true` 的 TLS 通路没有用例 | 低 | 在 `agent/svc` 集成用例里给假网关挂 `httptest.NewTLSServer`，断言 `Get` 成功 |
| 真实云端 COS/OSS/S3 的签名差异只用 MinIO 代过 | 低 | 设 `TC_S3_ENDPOINT`、`TC_S3_ACCESS_KEY`、`TC_S3_SECRET_KEY`、`TC_S3_BUCKET` 指向云桶跑 `core/objectstore/s3_integration_test.go` |
