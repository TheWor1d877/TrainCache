## 常驻命令

```bash
make -C bench bench-up
python3 bench/run.py compare --rho 2 --rate 300 --group traincache-cold --dry-run
python3 bench/run.py status
```

`make -C bench bench-up` 拉起整套装置：建 kind 集群、导入镜像、部署 MinIO 与控制面、生成数据并上传、挂 tc 限速，最后做两次冷读验证。各步幂等，集群与数据已存在时跳过。

`--dry-run` 只打印计划，不访问集群。每格打印 COND 名、数据字节、缓存字节、`--rate` 与 `--reps`。ρ 是数据集字节除以缓存容量，4 GiB 数据集在 ρ=2 下对应 2 GiB 缓存，先跑一遍核对格子数，再跑整族。

`python3 bench/run.py status` 只读 `~/tcd/bench/results/`，打印各族的完成情况，不访问集群。

数据在 `~/tcd/bench/data/`，产物在 `~/tcd/bench/results/`。
