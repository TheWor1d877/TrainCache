# controller 测试说明书

> 配套 design.md `7.1`、plan.md `7.2`、decisions.md `7.3`。

## 1. 测试范围

controller 是控制面组件：reconcile 跑在 controller-manager 进程，打分跑在 kube-scheduler 进程，管预热生命周期与 Scheduler 打分，不直接碰数据面。测试共 **55 个 `*_test.go` 文件**、**12,949 行测试代码**、**318 个 `Test` 函数**，覆盖 **19 个包**：api/v1alpha1、internal（包根，静态检查）、internal/{agentclient,config,consumeorder,gate,gwaa,logging,metrics,nodescore,scheduler,scorefmt,storage,webhook}、internal/controller/{dataset,warmup}、cmd/{controller-manager,webhook,scheduler}。

测试框架用标准库 `testing`，大量表驱动。k8s 对象流转由 controller-runtime 的 fake client（进程内内存 API 对象存储）与 interceptor（在指定 API 调用点注入 Conflict 等错误）驱动；跨组件链路用内存桩；gRPC 用 bufconn（进程内内存监听器，不开真实端口）；对象存储复用 core 的 mock Store。GWAA、Gate、Filter、scorefmt 是纯函数，直接喂 struct 断言。

概述：覆盖控制面全部核心链路；纯函数层（GWAA / Gate / scorefmt）测试密度最高，集成测试在进程内完成 k8s 对象流转，全量 `-race` 全绿。

cd controller && go test ./... -race -count=1
# 示例输出摘要

# ok   traincache/controller/internal/config              1.016s
# ok   traincache/controller/internal/consumeorder        1.022s
# ok   traincache/controller/internal/controller/dataset  1.794s
# ok   traincache/controller/internal/controller/warmup   3.102s   # 最重的一包
# ok   traincache/controller/internal/gate                1.019s   # 纯函数
# ok   traincache/controller/internal/gwaa                1.077s   # 纯函数
# ok   traincache/controller/internal/logging             1.018s
# ok   traincache/controller/internal/metrics             1.034s
# ok   traincache/controller/internal/nodescore           1.019s
# ok   traincache/controller/internal/scheduler           1.065s
# ok   traincache/controller/internal/scorefmt            1.022s
# ok   traincache/controller/internal/storage             1.650s
# ok   traincache/controller/internal/webhook             1.717s

# 只跑纯函数层（最快）
go test ./internal/gwaa/... ./internal/gate/... ./internal/scorefmt/... -v

# 跑 GWAA 分配主流程（gwaa_test.go 共 31 个 Test 函数：30 个 TestCompute* + 1 个 TestValidate）
go test ./internal/gwaa -run 'TestCompute' -v

# 跑门控判定（gate_test.go 共 14 个 Test 函数）
go test ./internal/gate -v

# 跑 MinUnmet 端到端链
go test ./internal/controller/warmup -run 'MinUnmet' -v

controller 依赖 k8s.io/apimachinery 与 controller-runtime，还依赖 core 与 agent（agentpb）包，靠根 `go.work` 解析，跑之前要在仓库根 `go work sync` 过一次。全部测试在进程内完成，不需要本地 API Server，也不需要 setup-envtest。

### 沉默腐蚀型逻辑专项（S1–S19）

沉默腐蚀指错了不报错、结果错但表面正常的逻辑。本表与上文文件清单按 M12 验收逐行核对（8.2 的覆盖判断指向此处）。

| # | 逻辑 | 腐蚀方式 | 专项测试策略 |
|-----|------------------------|------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| S1  | 块编号/StartChunk      | 少算/重复，静默读错块              | 不变量：`Σcount=TotalChunks`、区间无缝无重叠；随机 shard 组合 |
| S2  | 位图位序               | 顺序错位导致 rate 偏高             | 用可辨识块序列构造 `GetPreheatStatus` 位图，逐位断言 bit i↔chunks[i]；K_i=1/7/8/9；覆盖长度不足/多余位 |
| S3  | readinessTable 列顺序  | 节点重排导致分数串列               | 节点名乱序输入，断言列稳定升序；表尺寸不变量 |
| S4  | 门控首次达标时刻       | 反复重置导致永不放行或提前放行     | 注入时钟，模拟交错达标；断言只记录第一次 |
| S5  | slope 采样             | 间隔不足或负时间导致误判           | 乱序样本、相等时间戳、零间隔 |
| S6  | generation/seq 陈旧    | 旧响应覆盖新就绪度                 | 乱序响应注入；断言 generation 不回退、seq 严格递增且回退响应被丢弃 |
| S7  | 每任务 annotation 合并 | 并发读改写丢条目或跨任务互相覆盖   | 两个 task 并发写同一 Node 断言两个独立键均保留；同 task 注入 Conflict，重试后 `p` 条目并集完整；键格式与长度断言 |
| S8  | Webhook 幂等           | 重复 admission 重复加 gate         | 对同一 Pod 连续调用两次，断言 gate 只一个 |
| S9  | GWAA 回退/随机并列     | 不收敛时输出抖动；随机种子破坏约束 | 构造环状冲突，断言回退结果合法且 Warn；固定种子 100 次一致；随机种子仅断言每 Pod 至多一节点、约束满足、无可行节点才 unassigned |
| S10 | 轮询/重试退避          | 失败风暴或永久卡死                 | 故障注入：连续 Unavailable 后恢复；断言退避上限与恢复 |
| S11 | 资源释放               | ticker/conn 泄漏                   | `goleak` 风格断言（标准库方式：启动-关闭后 goroutine 数回落） |

| S13 | 配置默认值             | 环境变量拼写错误静默用默认         | 表驱动：每个变量缺失/非法/合法三态 |
| S14 | 日志脱敏               | Secret 泄漏                        | 捕获日志，断言不含敏感字段值 |
| S15 | status 体积            | 超限被 apiserver 截断              | 基准：P=64,N=256 序列化字节数断言 < 1MiB |
| S16 | 并发 patch             | 冲突被吞导致状态丢失               | 注入 Conflict，断言重试后最终状态正确 |
| S17 | 默认消费顺序兜底       | 部分 Pod 非法导致混合顺序或漏块    | 任一 Pod 空/越界/重复即全量 default；floor 区间无缝覆盖 `[0,T)` 且升序；`T<P` 拒绝；断言 `ConsumeOrderDefaulted` 事件与 `consumeOrderSource` |
| S18 | annotation 键编码      | 名称截断后碰撞或键超长             | 32 字符截断 + sha256 前 12 位；键名部分 ≤52；不同 namespace/同前缀不同 hash 不碰撞；编码可复现 |
| S19 | 整数门控               | 浮点舍入导致阈值边界漂移           | K=1/7/8/9 × threshold=0/0.8/0.9 矩阵；`required_i<=K_i`；`threshold>0` 且结果为 0 取 1 |
