# bench 文档导览

bench 在单机 kind 集群（5 节点，4 个 worker）上测分布式训练存储。tc 在 MinIO 出站路径上限速，造出「冷读绕远程、命中读本地」的带宽差；四轨合成数据按固定种子生成；TrainCache 与 direct/juicefs/fluid 四类组态按七个组态展开，吃同一份轨迹、同一个带宽档、同一块缓存容量。

| 文档 | 内容 | 什么时候翻 |
|---|---|---|
| [4.1 bench装置与禁令](<4.1 bench装置与禁令.md>) | 装置构成、文件作用（TrainCache 与非 TrainCache 分开）、参数总表、数据与产物落点、禁令、装置级故障 | 改装置、清磁盘、查参数 |
| [4.2 juicefs与fluid](<4.2 juicefs与fluid.md>) | 两类对照组的镜像准备、起组、预热、跑分、拆组与各自的坑 | 跑或重跑 juicefs/fluid |
| [4.3 TrainCache启动与实验](<4.3 TrainCache启动与实验.md>) | 镜像构建与导入、控制面拉起、新版本自跑、实验族启动、进度与排障 | 发新版本、跑实验 |
| [4.4 实验版本记录](<4.4 实验版本记录.md>) | 版本 × 实验族的矩阵，记录每个版本跑完的产物 | 决定新版本跑什么、找旧产物 |

常驻命令：

```bash
cd bench
make bench-up                                  # 从零拉起装置，各步幂等
make bench-quick TIER=S RATE=1000 REPS=3       # 新版本只跑 TrainCache 冷热
python3 bench/exp.py status                    # 实验族与完成度
```

数据在 `~/tcd/bench/data/`，产物在 `~/tcd/bench/results/`，repo 只放脚本与清单。实验假设、档位与判据见 [9.2 实验协议](<9.2 实验协议.md>)，任务与决策见 [9.1 plan](<9.1 plan.md>)。
