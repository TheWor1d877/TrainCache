常驻命令：

```bash
cd bench
make bench-up                                  # 从零拉起装置，各步幂等
make bench-quick TIER=S RATE=1000 REPS=3       # 新版本只跑 TrainCache 冷热
python3 bench/exp.py status                    # 实验族与完成度
```

数据在 `~/tcd/bench/data/`，产物在 `~/tcd/bench/results/`，repo 只放脚本与清单。实验假设、档位、判据与机时见 [4.4 实验协议](<4.4 实验协议.md>)，口径决策的 D 号见 [4.5 实验口径决策](<4.5 实验口径决策.md>)。
